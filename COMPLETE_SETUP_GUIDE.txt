2. HOW TO RUN FROM SCRATCH ON VISUAL STUDIO CODE
================================================================================

This section will guide you through setting up and running the entire
application from scratch using Visual Studio Code.

STEP 1: Open Project in VS Code

   1. Open Visual Studio Code
   2. Click: File → Open Folder
   3. Navigate to and select the "web project 1" folder
   4. You should see the folder structure in the left sidebar:
      - backend/ folder
      - frontend/ folder
      - COMPLETE_SETUP_GUIDE.txt
      - docs/ folder

STEP 2: Install Node.js Dependencies

   A) Install Backend Dependencies:
   
      1. Open terminal in VS Code:
         - Press: Ctrl + ` (backtick key, usually above Tab)
         - OR: Terminal → New Terminal
      
      2. Navigate to backend folder:
         cd backend
      
      3. Install dependencies:
         npm install
      
      4. Wait for installation to complete (may take 1-3 minutes)
         You should see: "added X packages"
      
      5. Verify installation:
         Check that "node_modules" folder was created in backend/
   
   B) Install Frontend Dependencies:
   
      1. Open a NEW terminal (keep backend terminal open):
         - Press: Ctrl + Shift + ` (opens new terminal)
         - OR: Terminal → New Terminal
      
      2. Navigate to frontend folder:
         cd frontend
      
      3. Install dependencies:
         npm install
      
      4. Wait for installation to complete (may take 2-5 minutes)
         You should see: "added X packages"
      
      5. Verify installation:
         Check that "node_modules" folder was created in frontend/

STEP 3: Create Environment Files

   A) Create Backend .env File:
   
      Method 1 - Using PowerShell (Recommended):
      1. Open terminal in VS Code (Ctrl + `)
      2. Make sure you're in project root (not in backend or frontend folder)
      3. Run this command:
         Copy-Item "backend\env.example.txt" "backend\.env"
      
      Method 2 - Manual:
      1. In VS Code, navigate to backend/ folder
      2. Find "env.example.txt" file
      3. Right-click → Copy
      4. Right-click in backend folder → New File
      5. Name it exactly: .env (with the dot at the beginning)
      6. Paste the contents from env.example.txt
   
      Edit the .env file with your settings:
      - PORT=5000 (backend server port)
      - NODE_ENV=development
      - MONGODB_URI=mongodb://localhost:27017/smartbasket
        (OR use MongoDB Atlas: mongodb+srv://username:password@cluster.mongodb.net/smartbasket)
      - JWT_SECRET=your_super_secret_jwt_key_change_this_in_production
      - JWT_EXPIRE=7d
      - FRONTEND_URL=http://localhost:3000
   
   B) Create Frontend .env File:
   
      Method 1 - Using PowerShell:
      1. In terminal (project root):
         Copy-Item "frontend\env.example.txt" "frontend\.env"
      
      Method 2 - Manual:
      1. Navigate to frontend/ folder
      2. Find "env.example.txt" file
      3. Copy it and rename to ".env"
      4. Edit the .env file:
         REACT_APP_API_URL=http://localhost:5000/api

STEP 4: Set Up MongoDB

   OPTION A - Using Local MongoDB:
   
      1. Ensure MongoDB is installed (see Dependencies section)
      2. Start MongoDB service:
         - Open PowerShell as Administrator
         - Run: net start MongoDB
         - OR check Services (services.msc) - MongoDB should be running
      3. Verify MongoDB is running:
         - Backend will connect automatically when started
   
   OPTION B - Using MongoDB Atlas (Cloud):
   
      1. Create account at https://www.mongodb.com/cloud/atlas
      2. Create a free cluster
      3. Get connection string from Atlas dashboard
      4. Update MONGODB_URI in backend/.env with your Atlas connection string
      5. Whitelist your IP address in Atlas dashboard

STEP 5: Start Backend Server

   1. Open terminal in VS Code (Terminal 1):
      - Press: Ctrl + ` (if no terminal open)
      - OR: Terminal → New Terminal
   
   2. Navigate to backend folder:
      cd backend
   
   3. Start the server:
      npm start
   
   4. Expected output:
      ✓ "Server is running on port 5000"
      ✓ "MongoDB Connected: ..." (if MongoDB is running)
      ✓ OR "MongoDB connection error: ..." (if MongoDB not running - server still works)
   
   5. Keep this terminal open and running
      - DO NOT close this terminal
      - The server must keep running
   
   6. Verify backend is running:
      - Open browser: http://localhost:5000
      - Should see JSON response with API information
      - If you see JSON, backend is working! ✅

STEP 6: Start Frontend Server

   1. Open a NEW terminal in VS Code (Terminal 2):
      - Press: Ctrl + Shift + ` (opens new terminal)
      - OR: Terminal → New Terminal
      - IMPORTANT: Keep Terminal 1 (backend) running!
   
   2. Navigate to frontend folder:
      cd frontend
   
   3. Start the React app:
      npm start
   
   4. Expected output:
      - Compilation starts (you'll see progress messages)
      - Takes 30-60 seconds on first run (be patient!)
      - "Compiled successfully!" message appears
      - Browser automatically opens to http://localhost:3000
   
   5. Keep this terminal open and running
      - DO NOT close this terminal
      - The frontend server must keep running
   
   6. Verify frontend is running:
      - Browser should open automatically
      - If not, manually go to: http://localhost:3000
      - You should see the SmartBasket homepage ✅

STEP 7: Verify Everything Works

   Now you should have:
   - ✅ Backend running on http://localhost:5000
   - ✅ Frontend running on http://localhost:3000
   - ✅ Two terminals open (one for backend, one for frontend)
   
   Test the application:
   1. In browser (http://localhost:3000):
      - Try clicking around the navigation
      - Try registering a new user
      - Try logging in
      - Browse products (if database is seeded)
   
   2. Check backend API:
      - Go to: http://localhost:5000
      - Should see JSON with all available API endpoints

STEP 8: (Optional) Seed Database with Sample Products

   If you want sample products in the database:
   
   1. Open a NEW terminal (or use backend terminal if you stop the server)
   2. Navigate to backend folder:
      cd backend
   3. Run seed script:
      npm run seed
   4. You should see:
      "Connected to MongoDB"
      "Cleared existing products"
      "Seeded X products successfully"
   5. Restart backend server (if you stopped it):
      npm start

HOW TO STOP THE SERVERS:

   When you're done working:
   1. Go to Terminal 1 (backend):
      - Press: Ctrl + C
      - This stops the backend server
   
   2. Go to Terminal 2 (frontend):
      - Press: Ctrl + C
      - This stops the frontend server
   
   3. Both servers are now stopped

QUICK START SUMMARY:

   1. Open project in VS Code
   2. Terminal 1: cd backend → npm install → npm start
   3. Terminal 2: cd frontend → npm install → npm start
   4. Wait for both to start
   5. Open browser: http://localhost:3000
   6. Done! ✅

6. TROUBLESHOOTING
================================================================================

PROBLEM: "MongoDB connection error"
SOLUTION:
   - Check if MongoDB is running (local) or Atlas connection string is correct
   - Verify .env file has correct MONGODB_URI
   - For local: Ensure MongoDB service is started (net start MongoDB on Windows)
   - For Atlas: Check IP whitelist and credentials
   - Note: Backend will start even if MongoDB fails, but database features won't work

PROBLEM: "Port 5000 already in use"
SOLUTION:
   - Find the process using port 5000: netstat -ano | findstr ":5000"
   - Kill the process: taskkill /PID <process_id> /F
   - OR change PORT in backend/.env to different port (e.g., 5001)
   - Update FRONTEND_URL in backend/.env if changed
   - Update REACT_APP_API_URL in frontend/.env to match

PROBLEM: "Port 3000 already in use"
SOLUTION:
   - React will automatically ask to use different port (usually 3001)
   - Accept the prompt, or manually kill the process using port 3000
   - Find process: netstat -ano | findstr ":3000"
   - Kill process: taskkill /PID <process_id> /F

PROBLEM: "Cannot find module 'X'"
SOLUTION:
   - Run npm install in the folder where error occurs (backend or frontend)
   - Check if package is in package.json
   - Delete node_modules and package-lock.json, then npm install
   - Try: npm cache clean --force, then npm install

PROBLEM: "CORS error" in browser
SOLUTION:
   - Check FRONTEND_URL in backend/.env matches your frontend URL
   - Ensure backend server is running
   - Check browser console for specific CORS error
   - Verify CORS is configured in backend/server.js

PROBLEM: "401 Unauthorized" errors
SOLUTION:
   - User needs to login first
   - Check if JWT_SECRET is set in backend/.env
   - Verify token is being sent in request headers
   - Check if token expired (default is 7 days)
   - Try logging out and logging back in

PROBLEM: Frontend shows blank page
SOLUTION:
   - Check browser console for errors (F12 → Console tab)
   - Verify all imports are correct
   - Check if backend is running and accessible
   - Verify REACT_APP_API_URL in frontend/.env
   - Try: npm start again in frontend folder

PROBLEM: "npm install" takes too long or fails
SOLUTION:
   - Check internet connection
   - Try: npm cache clean --force
   - Try: npm install --legacy-peer-deps
   - Check Node.js version: node --version (should be 16+)
   - Try using different npm registry if in restricted network

PROBLEM: "Cannot find path" when creating .env files
SOLUTION:
   - Ensure you're in the project root directory first
   - Use full path: cd "D:\Downloads D\web project 1"
   - Then: Copy-Item "backend\env.example.txt" "backend\.env"
   - OR navigate to the folder first: cd backend, then Copy-Item "env.example.txt" ".env"

PROBLEM: Backend starts but shows MongoDB connection error
SOLUTION:
   - This is NORMAL if MongoDB is not running
   - Backend will still run and API will respond, but database features won't work
   - Start MongoDB: net start MongoDB (Windows)
   - OR use MongoDB Atlas and update MONGODB_URI in backend/.env
   - Restart backend after fixing MongoDB connection
   - Verify: Backend API at http://localhost:5000 should still respond

PROBLEM: Frontend takes long time to start first time
SOLUTION:
   - This is NORMAL - React compilation takes 30-60 seconds first time
   - Subsequent starts are faster (10-20 seconds)
   - Wait for "Compiled successfully!" message
   - Check port 3000 is listening: netstat -ano | findstr ":3000"
   - Browser should auto-open, or manually go to http://localhost:3000
   - If timeout when accessing, wait a bit longer - compilation may still be in progress

PROBLEM: "Cannot find module" errors
SOLUTION:
   - Run: npm install in the folder where error occurs (backend or frontend)
   - Delete node_modules and package-lock.json, then run npm install again
   - Check Node.js version: node --version (should be 16 or higher)
   - Try: npm cache clean --force, then npm install

PROBLEM: VS Code terminal shows errors
SOLUTION:
   - Make sure you're in the correct directory (backend or frontend)
   - Check that Node.js is installed: node --version
   - Verify npm is working: npm --version
   - Try closing and reopening VS Code
   - Try opening a new terminal: Ctrl + Shift + `
