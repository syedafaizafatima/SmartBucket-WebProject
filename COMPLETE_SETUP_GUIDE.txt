================================================================================
                    SMARTBASKET - COMPLETE SETUP GUIDE
================================================================================

QUICK START:
1. Install Node.js (https://nodejs.org/) - LTS version
2. Install MongoDB Atlas (free) OR local MongoDB
3. Open project in VS Code
4. Install dependencies: npm install (in both backend and frontend)
5. Create .env files (see below)
6. Run: npm start (in backend) and npm start (in frontend)

================================================================================
2. SETUP IN VISUAL STUDIO CODE
================================================================================

STEP 1: Open Project
- File → Open Folder → Select "web project 1" folder

STEP 2: Install Backend Dependencies
- Terminal → New Terminal (Ctrl + `)
- cd backend
- npm install

STEP 3: Install Frontend Dependencies
- Terminal → New Terminal (Ctrl + Shift + `)
- cd frontend
- npm install

STEP 4: Create .env Files

A) Backend .env (backend/.env):
   Create file: backend/.env
   Add these lines:
   
   PORT=5000
   NODE_ENV=development
   MONGODB_URI=mongodb+srv://YOUR_USERNAME:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/smartbasket?retryWrites=true&w=majority
   JWT_SECRET=YOUR_JWT_SECRET_KEY_HERE
   JWT_EXPIRE=7d
   FRONTEND_URL=http://localhost:3000

B) Frontend .env (frontend/.env):
   Create file: frontend/.env
   Add this line:
   
   REACT_APP_API_URL=http://localhost:5000/api

================================================================================
3. GET MONGODB URI AND PASSWORD
================================================================================

OPTION A: MongoDB Atlas (Recommended - Free):
1. Go to https://www.mongodb.com/cloud/atlas
2. Sign up for free account
3. Create a free cluster (M0 tier)
4. Click "Connect" → "Connect your application"
5. Copy the connection string
6. Replace <password> with your database password
7. Replace <dbname> with "smartbasket"
8. Example: mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/smartbasket
9. Add your IP to whitelist (Network Access → Add IP Address)

OPTION B: Local MongoDB:
1. Install MongoDB Community Server
2. Start service: net start MongoDB (Windows)
3. Use: mongodb://localhost:27017/smartbasket

================================================================================
4. GET JWT SECRET KEY
================================================================================

Generate a secure random string. Options:

METHOD 1: Online Generator
- Go to https://randomkeygen.com/
- Copy a "CodeIgniter Encryption Keys" (64 characters)
- Use this as your JWT_SECRET

METHOD 2: Node.js Command
- Open terminal
- Run: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
- Copy the output (64 characters)
- Use this as your JWT_SECRET

METHOD 3: Manual (Simple)
- Create any long random string (at least 32 characters)
- Example: VXzOLMmfIUwKiSY9nlpGg7J1oZQkyDra1234567890abcdefghijklmnop

IMPORTANT: Keep JWT_SECRET secret! Don't share it publicly.

7. WHAT IS SMARTBASKET?
================================================================================

SmartBasket is a full-stack grocery shopping web application that helps users:

- Compare prices across multiple stores
- Create AI-powered shopping lists
- Get recipe recommendations based on dietary preferences
- Manage product subscriptions for regular deliveries
- Track financial spending and transactions
- Participate in group buys for bulk discounts
- Read and write blog posts about cooking and shopping
- Review products and share experiences

TECHNOLOGY STACK:
- Backend: Node.js + Express + MongoDB
- Frontend: React + Bootstrap
- Authentication: JWT tokens
- Database: MongoDB (Atlas or local)

ARCHITECTURE:
- RESTful API backend serving JSON data
- React SPA (Single Page Application) frontend
- JWT-based authentication
- MongoDB for data storage
- Responsive design with Bootstrap

10. TROUBLESHOOTING
================================================================================

Port 5000 in use:
- Change PORT in backend/.env to 5001
- Update REACT_APP_API_URL in frontend/.env

Port 3000 in use:
- React will ask to use 3001 - accept it

MongoDB connection error:
- Check MONGODB_URI in backend/.env
- Verify Atlas IP whitelist
- Backend still runs without DB (but features won't work)

npm install fails:
- Check internet connection
- Try: npm cache clean --force
- Verify Node.js version: node --version (should be 16+)

CORS errors:
- Verify FRONTEND_URL in backend/.env matches frontend URL
- Check REACT_APP_API_URL in frontend/.env

401 Unauthorized:
- User needs to login first
- Check JWT_SECRET is set in backend/.env
