===========================================
HOW TO RUN SMARTBASKET IN VS CODE
===========================================

STEP 1: CREATE ENVIRONMENT FILES
---------------------------------
1. Go to backend folder
2. Copy env.example.txt
3. Create new file named: .env
4. Paste the contents from env.example.txt

5. Go to frontend folder  
6. Copy env.example.txt
7. Create new file named: .env
8. Paste the contents from env.example.txt

STEP 2: INSTALL DEPENDENCIES
-----------------------------
Open terminal in VS Code (Ctrl + `)

Terminal 1 - Backend:
  cd backend
  npm install

Terminal 2 - Frontend:
  cd frontend
  npm install

STEP 3: SEED DATABASE (OPTIONAL)
---------------------------------
In backend terminal:
  npm run seed

STEP 4: START SERVERS
---------------------
Terminal 1 - Backend:
  cd backend
  npm run dev
  (Should show: Server is running on port 5000)

Terminal 2 - Frontend:
  cd frontend
  npm start
  (Browser opens to http://localhost:3000)

STEP 5: TEST THE APP
--------------------
1. Open browser: http://localhost:3000
2. Click "Register" to create account
3. Click "Products" to browse products
4. Try searching and filtering products

TROUBLESHOOTING
---------------
- Port 5000 in use? Change PORT in backend/.env
- MongoDB error? Check MongoDB is running or use Atlas
- Module not found? Delete node_modules, run npm install again
